# Security

## Reporting

Use GitHub's private vulnerability reporting on this repository. Please do not open a public issue for a vulnerability.

## What leaves your machine

- Title candidates are generated by the model you already use in Pi (`openai/gpt-6-luna` when available, otherwise the active model). This is the same provider path as normal Pi use.
- Only when the `typesafe` provider is logged in: a short generated synopsis, the candidate titles, the current title and a short preference string go to `https://api.typesafe.ai/v1/systemone`. The raw transcript, the user's hint and any tool output are never sent. Every field is run through a redactor first (keys, tokens, emails, IPs, absolute paths). Candidates that fail the redactor are dropped, not rewritten.
- Without Jev, nothing else is sent anywhere.

## Guards

- The API key is read on demand through `pi auth print-api-key --provider typesafe` (no shell, bounded output, 1 s limit, process group killed) and is only used as a bearer token for the one endpoint above. Redirects are refused and responses are size-limited.
- Jev can only pick among titles the extension already validated. It cannot supply or edit a title.
- Titles must be 24-240 characters with no control or bidi characters and must end with the date; anything else is rejected before `setSessionName`.
- Conversation text is treated as untrusted data in the prompt. Secrets are filtered before generation, and only a bounded slice of recent text is kept in memory.
- Automatic titling is skipped for resumed sessions, sub-agents, RPC/managed children and sessions you named yourself. It never overwrites a name you set.
- The skill text that enters the system prompt comes from the bundled file, or from `~/.agents/skills/titlewise/SKILL.md` if it is a regular file under 64 KiB.
- No runtime dependencies. The published package contains only the extension sources, the bundled skill and docs.

## Limits

Redaction is pattern based, not a full data-loss-prevention system. Do not put secrets in prompts and expect them to be recognised in every form.
